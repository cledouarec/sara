# sara-mcp

Model Context Protocol server for [SARA](https://github.com/cledouarec/sara) - **S**olution **A**rchitecture **R**equirement for **A**lignment.

This crate lets AI coding agents query a SARA knowledge graph through the [Model Context Protocol](https://modelcontextprotocol.io) instead of reading and cross-referencing Markdown files.
